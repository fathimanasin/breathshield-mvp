# BreathShield – Streamlit Prototype

## What this is
BreathShield is a proof-of-concept application built as part of the Allianz Tech Championship to explore rapid prototyping using Streamlit.

## What I built
- Developed a Streamlit-based interface for the application  
- Implemented core logic to process inputs and display results interactively  
- Focused on turning an idea into a working prototype quickly  

## Why I built this
I wanted to understand how quickly a functional product can be built using lightweight tools like Streamlit, especially for experimenting with ideas and user interaction.

## What I learned
- Rapid prototyping using Streamlit  
- Structuring Python scripts for interactive applications  
- Translating concepts into simple working interfaces  

## Future improvements
- Improve UI/UX for better usability  
- Expand functionality beyond proof-of-concept  
- Integrate more robust backend logic
